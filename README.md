# TanStack CSR Mini

Minimal client-side-rendered TanStack Router app. No server, no `@tanstack/react-start`, no devtools — just Vite + React + Router.

## Run

```bash
npm install
npm run dev
```

Opens at http://localhost:3000

## Build

```bash
npm run build
```

Output goes to `dist/`. Deploy `dist/` as static files (any static host works — no server needed).

## Package manager

npm (any of npm/pnpm/yarn will work; only a `package-lock.json` isn't included here so pick one).
